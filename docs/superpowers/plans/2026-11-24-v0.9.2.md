# v0.9.2 Implementation Plan: contrast and app-set fixes

> **Active.** Written 2026-11-24. Linear: GRE-616, GRE-620, GRE-617, GRE-619, GRE-598 (Design System project). Found while building Burnside's dashboard redesign (GRE-615), which carries local workarounds for three of them.

**Goal:** Fix five defects the dashboard redesign found in the kit and release them as v0.9.2, so Burnside can delete its local overrides.

**Architecture:** CSS-only changes in the existing component and theme files, each with a test in the repo's style (whole-selector `rules()` helpers, contrast computed from token values), plus gallery cases where a pattern gains a variant.

## Global Constraints

- Every text colour fixed here clears **4.5:1** in BOTH light and dark, computed from token values in a test (not a declaration pin alone).
- No new colour primitives. Use `color-mix(in srgb, <tone> N%, var(--ds-text))`, as v0.9.0's `.ds-message--danger/--success` already do.
- Nothing changes appearance outside the fixed selectors, except the GRE-598 token change, whose blast radius is stated in the README note.
- Public copy (README, gallery) uses no em dashes.
- Branch `lee/v0.9.2`. Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Merge and tag only after review, as v0.9.1 was.
- Do not commit the untracked `dist/fonts/README.md` (it is not part of this work).

## Tasks (one commit each, TDD)

1. **GRE-616, badge and hint contrast.** `.ds-badge--danger`, `.ds-badge--success` and `.ds-field[data-invalid] .ds-help` all reach ≥4.5:1 in light and dark against the backgrounds they actually sit on. A badge sits on its own tint (and the tint sits on the surface); a hint sits on `--ds-surface`, `--ds-bg` and `--ds-surface-raised`. Test: extend `test/contrast.spec.ts` (or `muted-contrast.spec.ts`) to compute each pair from the resolved tokens in both themes.
2. **GRE-598, dark muted on raised.** `--ds-text-muted` on `--ds-surface-raised` is 4.37:1 in dark. Lighten the dark `--ds-ink-muted` (or the dark muted token) by the smallest step that clears 4.5:1 on raised, and keep every other muted pairing passing. Test: muted text against every surface token, in both themes.
3. **GRE-620, sidenav item on a button.** `.ds-sidenav__item` resets `background`, `border`, `color`, `font`, `text-align`, `width`, `cursor` and `appearance`, so an `<a>` and a `<button>` render the same. Test: the rule exists with those properties (whole-selector). Gallery: the app section shows one item of each element. Browser check: in both themes, a button item's computed background equals the link item's, and the text contrast is ≥4.5.
4. **GRE-617, end-aligned menu.** Add `.ds-menu--end .ds-menu__list { left: auto; right: 0 }` (or the logical-property equivalent `inset-inline-start: auto; inset-inline-end: 0`). Test the rule. Gallery: a row-end menu using it. Browser check: at 375px the open list stays inside the viewport.
5. **GRE-619, list main cell.** `.ds-list__main` becomes `flex: 1 1 0` (keeping `min-width: 0`). Test the declaration. Gallery: a row with a long name. Browser check: at 375px the trailing action stays on the row's first line, at its right.
6. **Release.** README `## v0.9.2` above v0.9.1, one line per fix, plus the GRE-598 token change and what it affects. `package.json` 0.9.2. `pnpm build && pnpm test`. Commit `release: v0.9.2, contrast and app-set fixes`. After review: merge to main `--no-ff`, tag `v0.9.2`, push main and the tag, delete the branch.
