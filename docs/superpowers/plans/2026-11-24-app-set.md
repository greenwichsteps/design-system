## Review Focus

1. **Cascade order.** `app.css` sorts first among components (after `reset.css`), so any equal-specificity rule in a later file wins over it. `.ds-app` radius re-scoping is a custom-property override, so it is immune; but a `.ds-stack > * + *` margin is (0,1,0) and a later `.ds-section`, `.ds-card__title` etc. margin would beat it. Task 1 asserts the stack's selector, and the gallery check in Task 6 measures real gaps.
2. **The stack must not stretch inline children.** A button directly in a stack keeps its own width. Hence margins between siblings, not a flex column. Task 1 pins the selector shape.
3. **Phone width.** The sidebar must stay usable under 720px (unlike `.ds-shell__side`, which disappears). Task 2 asserts the media rule; Task 6 measures no horizontal scroll at 375px.
4. **Dark mode tints.** `color-mix` against `--ds-surface` changes per theme; contrast must be measured in both.
5. **Whole-selector matching.** Reuse v0.8.0's `rules()` approach (strip comments, split selector lists); never substring-match a class.
